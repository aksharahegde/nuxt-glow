## v1.3.0

[compare changes](https://github.com/aksharahegde/nuxt-glow/compare/v2.0.0...v1.3.0)

### 🚀 Enhancements

- Upgrade to Nuxt 4.5.1 and align dev toolchain (`@nuxt/test-utils` v4, `vue-tsc` v3, `@nuxt/eslint-config` 1.16, `@nuxt/module-builder` 1.0.3)
- Add `nuxt-mcp` to the playground and expose the Nuxt MCP server (`.mcp.json` for editor/CLI integrations)

### 🏡 Chore

- Raise minimum Node engine to `>=20.19.0` (required by Nuxt 4.5)
- Approve pnpm build scripts (`sharp`, `workerd`) via `allowBuilds`
